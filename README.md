# Daymark · 每日记录

一个轻量的每日事项记录与备忘录 Web 应用。纯前端，零依赖，打开即用。

**🔗 在线演示：https://kaye-star.github.io/daymark/**

## 功能

- **今日视图** — 按「学业 / 实习 / 其他」三栏归类，快速添加、勾选完成、一键删除
- **可编辑卡片** — 标题和备注直接就地编辑，输入即保存
- **历史记录** — 汇总所有已完成事项，附分类与完成时间
- **备忘录** — 独立笔记区，支持自动保存与 JSON 导出备份
- **响应式布局** — 侧边栏 + 主内容区，适配桌面与移动端

## 技术栈

纯静态三件套，无构建步骤、无框架、无依赖：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式与布局（含深色配色、进度环、卡片动效） |
| `app.js` | 全部交互逻辑与本地持久化 |

数据通过浏览器 `localStorage` 保存在本地（`daymark-tasks` / `daymark-notes`），**不上传服务器**。首次打开会载入一组示例数据，方便直接体验。

## 本地运行

```bash
git clone https://github.com/kaye-Star/daymark.git
cd daymark
open index.html        # macOS，或直接双击 index.html
```

## 部署

已启用 GitHub Pages，推送 `main` 分支即自动更新线上版本。

## 说明

本项目为前端演示作品。由于数据存在浏览器本地，每位访客的增删改只影响自己的浏览器，不会互相干扰。
